## Project Description
Chai Dhaba is a simple, responsive multi-page website created as part of Lab 12. It represents a traditional Pakistani tea café where visitors can explore the menu, view food and drink pictures, and contact the café through a demonstration form.

## Website Pages
1. **Home:** Introduction to Chai Dhaba.
2. **Menu:** Displays food and drink categories.
3. **Gallery:** Shows pictures of chai and snacks.
4. **Contact:** Includes a contact form with a JavaScript confirmation alert.
